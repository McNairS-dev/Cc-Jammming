# Jammming - a (minimal) Spotify Client Project 
## User Stories
### Search
	... for tracks by name
As a user I can
+ request a list of song tracks
+ view a list of tracks that meet the search criterion
+ for each track, the list will display
+   song name
+   artist name
+   album name

### Add Track to Playist
As a user I can
+ add a track from the Search Results to the Playlist
+ remove a track from the Playlist
